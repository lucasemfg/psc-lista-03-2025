# 📚 PSC – Lista 03 (2025)

Repositório com os **exercícios da Lista 03** da disciplina de **Programação (PSC)**, feitos em **Java** como parte das atividades da faculdade.

---

## 🧠 Descrição

Este repositório contém implementações em Java abordando conceitos básicos aprendidos em sala de aula, tais como:

- Entrada e saída de dados
- Estruturas de controle
- Operadores
- Lógica de programação

Os exercícios foram realizados como parte das atividades avaliativas da lista 03 do curso.

---

## 📁 Conteúdo

Arquivos neste repositório:

| Arquivo                   | Descrição                                    |
|--------------------------|-----------------------------------------------|
| `CalcSimples.java`       | Cálculos aritméticos simples                  |
| `EqSegundoGr.java`        | Resolução de equação do 2º grau               |
| `ExercQuat.java`         | Exercício envolvendo números quadráticos      |
| `MaquinaSalga.java`      | Simulação de máquina de venda automática      |
| `NumerosComMat.java`     | Exercícios com matriz de números              |
| `NumerosMaMen.java`      | Verificação de maior e menor número           |
| `SortDoisNum.java`       | Ordenação de dois números                     |
